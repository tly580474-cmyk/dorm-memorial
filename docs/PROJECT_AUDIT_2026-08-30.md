# 项目优化与信息安全审查（2026-08-30）

基线提交：`31c2740`。由主代理和三名子代理审查 Go 接口、身份认证、业务数据、媒体与存储，以及 Vue 前端；先排查功能与性能问题，再复查安全边界。所有改动仅保存在本地，未推送、未部署、未重启现有服务。

## 功能与性能修复

| 范围 | 问题与修复 |
| --- | --- |
| 会话查询 | 合并会话、用户和资料查询；活跃时间最多每分钟写一次，减少轮询和媒体请求造成的 SQLite 写入。每次请求仍检查账号状态、过期和撤销。 |
| 登录状态 | 数据库暂时不可用不再误删登录 Cookie；退出登录必须成功撤销会话，失败时前端保留当前界面并恢复轮询。 |
| 媒体响应 | `HEAD` 不再消费对象正文，仍关闭已打开的流。 |
| 前端异步状态 | 详情、评论、通知、会话、后台、内容刷新及分页增加请求代际检查，防止旧响应覆盖新页面。 |
| 前端资源释放 | 登出及卸载停止录音轨道、清理定时器和头像对象 URL；处理晚返回的麦克风权限请求。录音 MIME 与文件扩展名一致。 |
| 富文本渲染 | 按帖子对象及内容缓存清理、解析和高亮结果，减少重复 DOM 解析。 |
| 内容查询 | 标签和附件按一页批量加载；管理员编辑文章按作者校验附件归属；缺失发布时间的 feed 游标使用更新时间。 |
| 旧数据分页 | 游标保存数据库原始时间文本，避免历史 `RFC3339Nano` 小数精度变化导致跳项。不对真实数据库做时间格式批量转换。 |
| 媒体生命周期 | 处理后台衍生资源生成与删除并发时的登记和清理；缓存通过版本检查拒绝旧读取结果覆盖新内容；清理遗留缓存暂存文件。 |
| 备份校验 | 在 SQLite 完整性检查之外增加外键检查，拒绝关系已损坏但文件结构正常的备份。 |
| 检查流程 | 新增 `check-project.ps1`；仅检查正式源码包，构建输出至 `build/review-web`，不覆盖运行中的 `web/dist`。 |

## 安全修复

| 范围 | 防护 |
| --- | --- |
| Go 标准库 | 最低版本升至 **1.26.7**。旧 1.26.1 被 `govulncheck` 报告有 16 项与调用路径相关的标准库漏洞；升级后重新检查。选择同系列补丁，未迁移到 1.27。 |
| 登录和注册 | 两个接口共享每个 TCP 对端 5 分钟 20 次的限制、最多 2 个并发处理槽、15 秒请求读取期限；限制限流状态表大小。不信任客户端伪造的转发 IP 头。 |
| CSRF | 使用 Go 标准库 `CrossOriginProtection`，同时覆盖 Fetch Metadata 与没有该头时的 Origin 校验；不再只拒绝 `cross-site` 一种情况。 |
| 媒体跨站读取 | 媒体 GET/HEAD 另行拒绝跨站和同站不同源的浏览器请求，避免外站携带成员 Cookie 触发延迟转码；正常同源及地址栏访问保持可用。 |
| 浏览器执行策略 | 增加 CSP，禁止第三方脚本、对象嵌入和任意 iframe；保留裁剪所需内联样式、本站媒体和既有外链视频能力。 |
| 富文本和外链 | 前端对 `v-html` 增加标签、属性及协议白名单，清理危险节点；图片仅允许本站媒体接口；外部视频及 iframe 地址另行校验并减少 Referer 泄漏。后端现有净化与访问权限检查继续保留。 |
| 私有缓存 | API 默认 `no-store`；成功的私有媒体使用 `private, no-cache`，命中缓存前重新校验授权，避免注销或删除后仍在浏览器直接使用一周内的新鲜缓存。 |
| 私信附件 | 媒体授权要求关联消息仍为 `sent`，阻止消息撤回后继续通过媒体 ID 读取。个人页可见留言按既有约定对全体成员可见，未误改为私信权限。 |
| 错误泄漏 | 仅显式 `ValidationError` 的应用文案可返回客户端；未知账号、内容和消息错误返回通用 500，避免泄漏 SQL、表名或内部路径；包装错误也只返回内层安全文案。 |
| 账号保护 | 最后一名活跃管理员不能自行注销；账号修改使用原密码哈希作为并发条件，防止旧资料请求恢复旧密码；密码限制与 bcrypt 的 72 字节上限一致。 |
| 配置校验 | 规范化并校验环境名称；生产要求 HTTPS 公共地址及 Secure Cookie；公共地址禁止嵌入凭据。 |
| 音频资源 | 单文件上限 16 MiB，HTTP 层提前拒绝超限；暂存读取有长度边界，按容器头检查 MIME，避免仅凭 `audio/*` 接受任意文件。 |
| 视频解析 | FFmpeg/ffprobe 限制协议与输入容器，排除网络协议、播放列表、concat 和图片序列等引用额外资源的输入。 |
| AList | 凭据/API 请求拒绝重定向，避免 307/308 重放认证正文或转发令牌；原始文件 GET 保留正常 CDN 跳转。拒绝危险 raw URL 协议及嵌入凭据。 |

## 部署和剩余边界

1. **已有运行进程仍是旧版本。** 需要在上传任务结束后，按原流程停止旧应用并运行 `start-local.ps1`，让新前后端一起生效；本轮未替换在线二进制或静态目录。新缓存策略只影响新响应，旧版已经缓存的媒体需清理浏览器缓存；已下载的文件无法远程撤回。
2. `golang.org/x/crypto` 模块中的旧 OpenPGP 包有模块级提示（`GO-2026-5932`，无修复版本）。本项目使用 bcrypt，不导入或调用 OpenPGP，因此没有为了消除无关模块提示更换密码实现。
3. 当前限流按 TCP 对端计数。经 Caddy、Nginx 或 FRP 汇聚到同一地址的成员会共享该额度；扩大用户规模或公网部署时，应由入口代理增加基于真实客户端地址的限流，不能直接信任任意 `X-Forwarded-For`。
4. 外链视频会访问第三方站点。为兼容原有链接，CSP 保留 HTTP(S) 媒体来源；HTTPS 页面仍受浏览器混合内容策略约束。只允许固定可信来源需要另行确定产品允许的域名。
5. 音频检查是有界的容器头校验，不是完整音频解码或服务端时长认证；前端 60 秒录音限制不应当视为服务端安全边界。
6. 未对真实 AList、FRP、生产系统权限、网盘账号和运行数据做配置变更或破坏性测试。未进行生产负载基准、真实 CDN/网盘端到端回归或移动设备实测。
7. Go 工具链安装后的临时发行包副本留在被忽略的 `build` 目录：清理命令同样被环境策略拒绝。正式工具链已通过官方版本包装器安装，项目可正常自动选用 1.26.7；上述临时副本不纳入 Git，也不参与检查脚本的源码扫描。
8. 历史时间字段仍是可变小数精度的文本，本轮保证分页游标与原始排序键一致，但没有重写历史时间。极细粒度消息顺序及统一时间排序仍需另行设计整型时间/序列或完整迁移；未经充分验证的时间补偿方案已撤回。
9. 媒体生命周期锁和任务去重在单进程内生效。多实例共享同一数据库和对象路径时，数据库查询与远端删除不具备跨进程原子性；扩容前需要另行设计分布式任务与对象登记。锁获取失败时优先保留可能已登记的文件，可能留下待维护清理的孤立派生对象。
