# 阶段 0：AList 存储链路验证

当前切片提供一个不落盘缓存上传内容的 Go `ObjectStorage` 原型，以及可对真实 AList/夸克目录执行上传、校验、移动和清理的探针。

## 已实现

- `PUT /api/fs/put` 流式上传，显式设置 `Content-Length`。
- `POST /api/fs/get` 获取对象元数据与临时读取地址。
- 下载与 Range 请求透传。
- 移动、重命名和删除。
- 根目录隔离及 `..`、反斜杠和 NUL 路径拒绝。
- HTTP 状态与 AList 业务错误到统一存储错误的映射。
- 基于 `httptest` 的模拟集成测试，不依赖真实凭据。

## 本地测试

```powershell
go test ./...
go test -race ./...
```

## 真实 AList 探针

复制 `.env.example` 中的变量到当前终端环境，但不要提交真实 Token：

```powershell
$env:ALIST_BASE_URL = 'http://127.0.0.1:5244'
$env:ALIST_USERNAME = 'dorm-memorial'
$env:ALIST_PASSWORD = '<password>'
$env:ALIST_ROOT = '/dorm-memorial/probe'
go run ./cmd/storage-probe
```

使用真实大文件验证流式行为：

```powershell
go run ./cmd/storage-probe -file 'D:\media\large-video.mp4'
```

探针依次执行上传、远端大小检查、完整下载 SHA-256 校验、移动/重命名和删除。只有显式传入 `-keep` 时才保留测试对象。

浏览器复制的 `ALIST_TOKEN` 只适合短时诊断；用户注销或权限变化后可能失效。配置专用用户名和密码时，探针会在每次运行前登录并取得新 Token，且不会输出密码或 Token。

### 2026-08-25：2.545 GiB 4K MP4

- 文件大小：2,732,214,415 字节（2.545 GiB）。
- 上传：7.539 秒，表观速度约 345.62 MiB/s；该速度远超链路带宽，判断为夸克命中秒传或服务端去重，不能作为真实上传吞吐。
- Range：0.669 秒，远端前缀与本地一致。
- 完整下载：8 分 8.994 秒，约 5.33 MiB/s。
- SHA-256：`24ac35642f8bfed1a26323f3e6d9fd464467ebcb6926274991a6e2a57e8b37dd`。
- Go 堆峰值：0.70 MiB；Go 运行时系统内存峰值：6.77 MiB。
- 总耗时：8 分 18.181 秒。
- 结果：上传、父目录刷新、Range、最终完整下载哈希校验、移动、重命名和删除全部通过，但下载链路并非连续稳定。
- 稳定性问题：用户观察到网卡负载在下载过程中停止数十秒、随后恢复。AList 日志证实在 `22:31:33` 的第 24 个分块和 `22:34:35` 的第 42 个分块均发生 `unexpected EOF` 并重试。
- 结论：重试机制保证了最终文件完整性，但间歇性分块失败可能导致视频在线播放卡顿；单次短时网卡采样不能证明全程稳定。该现象也可能受到当前本地网络或代理链路波动影响，暂不阻塞开发，待实际部署后按秒记录吞吐、停顿时长和重试次数并复测。
- 清理结果：刷新 `/dorm-memorial/probe` 后对象数为 0，无远端测试文件遗留。
